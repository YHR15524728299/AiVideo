# 扁平交付与锁屏后台运行设计

## 目标

1. 用户打开单个任务目录即可找到最终视频，不再进入多层 `delivery/youtube/`。
2. 任务运行时允许 Windows 锁屏，并临时阻止系统自动睡眠；任务结束、失败或进程退出后恢复原电源行为。
3. GUI 只负责启动与观察，实际流水线由独立 Worker 进程执行；关闭 GUI 不终止任务。
4. GitHub 只接收源码、测试、示例配置和必要文档，禁止上传生成视频、测试产物、数据库、日志、缓存、密钥和个人配置。

## 非目标

- 不支持用户注销后继续运行。
- 不注册 Windows 服务或计划任务。
- 不在电脑已经睡眠时执行计算。
- 不删除数据库中用于恢复和审计的任务状态。

## 交付结构

任务完成后，任务目录根部只暴露以下五个用户文件：

```text
outputs/<job_id>/
├── 最终视频.mp4
├── 无字幕视频.mp4
├── 封面.jpg
├── 发布文案.md
└── 验收摘要.json
```

运行期中间产物统一放入 `outputs/<job_id>/_work/`。`_work/`包含脚本、研究、音频、字幕、素材、母版、QA细节和发布清单。完成交付后执行白名单清理：

- 保留根部五个用户文件。
- 保留 `_work/status.json`、恢复所需远程任务记录、权威哈希清单和不可再生素材。
- 删除可再生成的预览、重复转码、接触表、临时帧、失败下载、旧交付副本和 `.pending`目录。
- 清理失败不影响已生成的最终视频；失败原因写入验收摘要。

现有任务迁移时，旧图片拼接版本属于已明确拒绝的派生文件，删除；真实动态素材属于高成本不可再生资产，迁入 `_work/assets/`保留。

## 后台Worker

新增独立后台启动入口，负责：

1. 校验 Job ID 和环境。
2. 以独立进程运行 `python -m aicf autopilot --job <job_id>`。
3. 将标准输出和错误写入 `logs/<job_id>.log`，不依赖 GUI 管道。
4. Worker 启动后写入包含 PID、Job ID、启动时间和日志路径的运行记录。
5. Worker 到达 `COMPLETED`、`FAILED_NEEDS_ATTENTION`或不可恢复失败时退出；不得无限轮询已完成任务。

GUI 启动任务时调用后台启动器，而不是持有流水线子进程。GUI 通过数据库状态和日志文件显示进度；关闭后重新打开仍能查看原任务。

## 锁屏与电源

Worker 运行时使用 Windows `SetThreadExecutionState`请求 `ES_CONTINUOUS | ES_SYSTEM_REQUIRED`：

- 允许显示器关闭和系统锁屏。
- 阻止任务期间自动系统睡眠。
- 不模拟键鼠，不改变用户永久电源计划。
- 在正常完成、失败、异常和 `KeyboardInterrupt`的 `finally`路径中调用 `ES_CONTINUOUS`释放请求。
- 非 Windows 平台使用空实现，保持CLI可测试。

如果电脑被用户手动强制睡眠、关机或注销，进程仍可能暂停或终止；已有状态机负责唤醒或重启后的断点恢复。

## 安全与隐私

- `.gitignore`继续忽略 `outputs/*`、`data/*`、`logs/`、`.env*`和 `config/*.yaml`。
- 上传前运行已跟踪文件扫描与待提交差异扫描，拦截常见密钥、用户绝对路径、媒体、SQLite、缓存和运行日志。
- 仅显式暂存本功能的源码、测试、示例配置和文档。
- 不使用 `git add -A`。
- 推送前列出提交文件并验证其中没有 `outputs/`、`data/`、`logs/`、个人配置或本机路径。

## 错误处理

- 后台进程已存在：返回现有 PID，不重复启动。
- PID记录存在但进程已退出：标记为陈旧并允许恢复。
- 电源请求失败：任务停止并明确报错，不假装具备锁屏能力。
- 最终文件提升失败：保留原交付，使用原子替换，不产生半成品。
- 清理失败：最终交付仍有效，但验收摘要记录残留路径。

## 验证

1. 单元测试：电源请求申请和释放、异常路径释放、重复启动拒绝、陈旧PID恢复。
2. 集成测试：GUI启动后关闭，Worker仍运行并更新状态；锁屏语义通过注入式Windows API测试。
3. 交付测试：任务根部只出现五个用户文件，最终视频哈希与清单一致。
4. 回归测试：完整 `pytest`、`doctor`、`git diff --check`。
5. 隐私检查：提交文件白名单、密钥扫描、媒体和运行目录排除。

- 当前任务 `FED_RATE_20260731`完成迁移，根部可直接打开 `最终视频.mp4`。
- 新任务自动使用同一扁平交付规则。
- 锁屏后 Worker持续运行，任务期间系统不会自动睡眠。
- GUI关闭不终止 Worker。
- Worker终态后自动退出并释放电源请求。
- GitHub远端只包含允许的工程文件。
